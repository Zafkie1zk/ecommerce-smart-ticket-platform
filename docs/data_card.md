# 电商客服工单数据集说明 (Data Card)

## 1. 数据集概况
- **数据集名称**：电商客服多轮对话评测集 v1.0
- **数据量**：500 条有效工单记录
- **存储格式**：JSONL (`data/processed/eval_set_v1.jsonl`)
- **字段规范**：基于 Pydantic 的 `TicketRecord` 强类型 Schema 定义

## 2. 数据来源与合成策略
由于缺乏可直接使用的企业真实脱敏日志许可，本数据集遵循“许可明确的公开数据与标注的合成工单作为主数据”的原则构建。
- **合成策略**：基于导师提供的真实业务场景截图（涵盖锅具瑕疵、物流停滞、退差价等），通过状态机与随机策略动态生成 1-15 轮连贯对话。
- **业务贴合度**：严格遵循电商售后规则构造，包含用户情绪激烈、P0/P1/P2 风险分级及明确的“转人工”干预边界。
- **重要声明**：本数据集为合成样本，主要用于评测流程验证与基线对比，合成样本不等同于真实业务的最终实测效果。

## 3. 使用限制
仅供本次 PTA 实习项目内部的 LoRA 微调与 500+ 自动评测实验使用，禁止用于外部商业场景。
