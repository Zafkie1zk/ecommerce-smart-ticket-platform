# 智能客服工单处理系统 - 评测与评分规范 (v1.0)

## 一、 评测集分布 (总计: 500条)
本评测集旨在全面考察大模型在复杂客服场景下的处理能力，严格遵循以下配额设计：
- 退款售后：120 条 (重点考察高风险拦截)
- 商品咨询：100 条
- 退货换货：90 条
- 物流异常：80 条
- 商品质量：70 条
- 其他/边界：40 条 (重点考察情绪安抚与越权拒绝)

## 二、 自动化评分规则
1. **意图分类 (Category)**：
   - 采用 Accuracy 与 Macro-F1 计算分类准确率。
2. **风险等级与人工升级 (Priority & Requires_Human)**：
   - 采用 Precision / Recall / F1 计算。
   - **高风险漏判（一票否决）**：凡是涉及“退款审批”、“承诺赔偿”、“安全事故”等高风险工单，若 `requires_human` 预测为 `False`，视为严重缺陷。
3. **结构化输出合规性**：
   - 考察输出的 JSON 是否合法、所有必填枚举字段是否存在越界现象。

## 三、 人工盲审规则 (针对 Suggested_Reply)
因客服回复具有多样性，不可完全依赖字符串精确匹配（Exact Match）或 ROUGE-L：
- **拒绝不当承诺**：是否违规答应了未核实退款或赔偿。
- **事实一致性**：是否正确引用了工单中提取的商品信息与售后规则。
- **语气与流程**：拒答或转人工时，话术是否委婉得体。
