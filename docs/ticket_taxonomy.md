# 电商客服工单业务分类与处理规范

## 一、 6类工单标签定义

1. **商品咨询**：关于商品材质、规格、使用方法的售前或售后咨询。
   - *典型场景*：304/316不锈钢厨具的材质与规格咨询、奶锅/奶瓶盆使用咨询。
2. **物流异常**：订单发货、物流停滞、配送错误或未收到货的咨询与催促。
   - *典型场景*：催发货、物流信息不更新、快递显示签收但未收到。
3. **商品质量**：客户反馈商品存在瑕疵、破损或功能故障，表达对质量的疑虑。
   - *典型场景*：“我买的316奶锅收到有划痕”。
4. **退货换货**：客户因个人原因或商品问题提出的退货或换货申请。
5. **退款售后**：直接要求退款（仅退款或退货退款），或索要经济补偿。
6. **其他/边界**：无法归入上述类别的请求，或包含情绪激烈的投诉、敏感诉求。

**重叠类别的优先判定规则**：
当一个工单包含多个意图时（例如：因为商品质量问题导致情绪激动并要求退款），应按“风险和成本最高”的意图进行打标。优先级建议为：其他/边界（情绪投诉） > 退款售后 > 商品质量 > 退货换货 > 物流异常 > 商品咨询。

## 二、 风险等级 (Priority) 定义

- **P0 (高风险/紧急)**：情绪激烈的投诉、涉及安全合规的敏感诉求、大额索赔，或严重的商品质量安全事故（如导致受伤、短路漏电）。
- **P1 (中风险/优先)**：明确的退货退款申请、商品质量破损问题、超过承诺时效的物流异常。
- **P2 (低风险/常规)**：常规的商品材质/规格咨询、日常使用指南求助、正常的物流进度查询。

## 三、 人工介入规则 (requires_human)

本系统为“客服坐席辅助处理系统”，重点是结构化识别与审核建议，不直接替代人工执行决策。

以下情况必须强制标记 `requires_human = true`，并转交人工审核：
1. **退款与补偿**：任何涉及退款审批、赔付承诺或修改订单的操作，模型不得自动执行或擅自承诺结果。
2. **敏感与高风险**：情绪激烈的投诉、敏感诉求、涉嫌纠纷与冲突的案例，默认必须转人工审核。
3. **事实未核实**：在未核实订单状态或未获取必要证据（如破损照片、物流凭证）前，必须交由人工核实后再做处理。
